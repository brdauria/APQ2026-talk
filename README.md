# AIMD Markov-modulated exit problems - EURANDOM talk

Open `index.html` in a browser. The deck uses Reveal.js 5 from jsDelivr and the Reveal MathJax plugin, following the structure of the provided example project.

Controls:
- Arrow keys or space: move through slides.
- `S`: speaker notes, when served from a local web server.
- Add `?print-pdf` to the URL to print/export as PDF from the browser.

This revision is prepared for the 40-minute invited talk at the EURANDOM workshop
"Applied Probability and Queues" (5-7 October 2026), on the day honoring Offer Kella.

The main talk runs through slide 28. Slides 29-30 are backup/reference slides.
The downward one-sided calculation uses the corrected Green-operator formulation,
and the final section develops reflection at the running minimum through the restart
equation and the Kella-Yor martingale.
